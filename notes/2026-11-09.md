# Catatan 2026-11-09
untuk hari ini 3 hal yang dikerjakan atau dipelajari adalah:

1. setting environment github untuk melakuakn pembelajaran cloud 
2. Root vs user lain: 

- root punya akses tanpa batas dan tidak bisa dibatasi.
- Prinsip least privilege: beri izin seperlunya.
- menggunakan root bukan akun admin karena menimbang skala yang akan digunakan hanya masih personal maka tidak perlu untuk membuat user lain

3. User vs Role
- User: identitas untuk orang, kredensialnya permanen.
- Role: identitas sementara yang dipinjam, misalnya oleh EC2 atau Lambda.

4. Kredensial jangka panjang vs sementara
- Access key itu permanen, jadi berisiko kalau bocor.
- aws login memberi kredensial sementara yang diperbarui otomatis.

5. Region dan Availability Zone

- Region adalah lokasi fisik pusat data. AZ adalah pusat data terpisah dalam satu region.
- Jakarta (ap-southeast-3) termasuk region opt-in.
- menggunakan us-east-1 untuk personal karena region jakarta masih perlu di verivikasi sendiri
